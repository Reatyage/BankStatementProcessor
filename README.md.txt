## 🎯 О проекте

**Bank Statement Processor** решает реальную проблему бухгалтеров и финансовых специалистов — рутинную обработку банковских выписок из разных форматов (PDF, Excel, TXT, CSV) и подготовку данных для импорта в 1С.

### Проблема
- Банки предоставляют выписки в разных форматах
- Ручной ввод данных в 1С занимает часы
- Сложно определить категории операций и контрагентов
- Ошибки при ручном вводе

### Решение
- Автоматический парсинг всех популярных форматов
- **ИИ-матчинг** контрагентов через локальную модель Qwen 2.5
- Автокатегоризация операций
- Генерация XML в формате 1С:ClientBankExchange
- Работа полностью офлайн — данные не покидают компьютер

## ✨ Возможности

### 🧠 Интеллектуальная обработка
- **Гибридный ИИ-матчинг** — комбинация нечёткого поиска (FuzzySharp) и локальной LLM (Qwen 2.5 через Ollama)
- **Автокатегоризация** операций: Аренда, Закупки, Зарплата, Налоги, Банковские услуги и др.
- **Панель сомнительных операций** — ИИ помечает неуверенные совпадения для ручной проверки
- **Нормализация контрагентов** — "ИП Иванов" и "Индивидуальный предприниматель Иванов" распознаются как один контрагент

### 📂 Работа с файлами
- Поддержка форматов: **TXT** (1СClientBankExchange), **PDF**, **Excel** (.xlsx), **CSV**, **ZIP-архивы**
- Автоматический мониторинг папки через `FileSystemWatcher`
- Обработка новых файлов без участия пользователя

### 🎨 Современный интерфейс
- **Glassmorphism-дизайн** с прозрачностью и градиентами
- **Системный трей** — приложение работает в фоне, сворачивается по клику на крестик
- **Динамические углы** журнала операций при прокрутке
- **Подробное логирование** с ротацией по дням (Serilog)

### 🔒 Безопасность
- Полностью **офлайн-работа** — данные не отправляются в облако
- Локальная ИИ-модель работает на вашем компьютере
- Пароли и конфиденциальные данные хранятся локально

| **Иконки в трее** | H.NotifyIcon.Wpf | Работа с системным треем |
| **Конфигурация** | Microsoft.Extensions.Configuration | Чтение JSON-настроек |
